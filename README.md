# Сундучок

> Мой первый проект на C#. Консольная карточная игра про сбор «сундучков».

---

## Описание

**Сундучок** — простая консольная карточная игра на C#. Два игрока по очереди спрашивают друг у друга карты по номиналу. Собери все 4 карты одного номинала — и у тебя **сундучок**!

Это мой **первый проект на C#**, но игра работает и играется до конца.

---

## Правила

1. **Колода и раздача**
   - Стандартная колода из 52 карт перемешивается.
   - Каждому игроку раздаётся по **5 карт**.
   - Остальное — колода добора.

2. **Ход**
   - В свой ход ты выбираешь карту из руки по её **номеру** (а не по названию).
   - Ты спрашиваешь у соперника карту того же **номинала**.

3. **Ответ**
   - **У соперника есть** — ты забираешь **все** карты этого номинала.
   - **У соперника нет** — ты берёшь **одну карту** из колоды.

4. **Сундучки**
   - Собрал **4 карты одного номинала** — они образуют **сундучок** и уходят из руки.
   - Каждый сундучок = **1 очко**.

5. **Пустая рука**
   - Если рука пуста, а в колоде ещё есть карты — ты автоматически добираешь одну.

6. **Конец игры**
   - Игра заканчивается, когда **колода опустеет**.
   - Побеждает тот, у кого **больше сундучков**.
   - Если поровну — **ничья**.
